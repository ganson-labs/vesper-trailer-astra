# VESPER — Последний свет

Кинематографичный трейлер вымышленной игры. Длительность — **64 секунды**, формат — **2.39:1**, изображение и оригинальная музыка создаются при показе.

## Запуск на Windows

В PowerShell, из этой папки:

```powershell
.\start.cmd
```

Откроется отдельное окно Edge или Chrome; трейлер начнётся автоматически со звуком. Терминал оставьте открытым. На этом компьютере Node.js и зависимости уже установлены. После установки зависимости интернет для показа не нужен. Если открывать страницу вручную в обычном браузере, нажмите «Начать путешествие»: браузер требует жест пользователя для звука.

`F` — полный экран; `Пробел` — пауза; `R` — повтор; `M` — звук. Кнопки появляются при движении мыши. После финала доступен повтор. Закрытие терминала / Ctrl+C останавливает локальный сервер. Браузер использует собственный профиль в `.runtime/browser` и не меняет обычный профиль.

## Что происходит

Странник несёт последнюю искру через затопленное царство. Солнце гаснет. Над океаном просыпается древняя машина. Сквозь ночь солнечный скиф идёт к вратам — и возвращает рассвет.

Десять планов: рассвет, руины, странник, затмение, ночной облёт, два плана погони, приближение к вратам, пробуждение и финальное раскрытие мира с титром.

## Как это сделано

- **Мир:** детерминированный рельеф, базальтовые колонны, архитектура, кольцо из отдельных камней, странник с анимируемым плащом, скиф, птицы и частицы. Все объекты построены из вычисляемой геометрии.
- **Изображение:** GLSL-небо, облака, затмение, звёзды, полярное сияние, волны, преломлённые отражения сцены, анимированная поверхность врат; динамический свет, тени, свечение и цветокоррекция. Титры — DOM/CSS с системными шрифтами.
- **Звук:** оригинальная партитура для Web Audio: осцилляторы, синтезированные колокола, низкие ударные, шум ветра, струнные и медные тембры, арпеджио. Шум и импульс реверберации генерируются математически при запуске; готовых сэмплов нет.
- **Синхронизация:** монтаж следует времени аудиоконтекста; пауза останавливает и звук, и картинку. Сворачивание окна ставит показ на паузу.
- **Зависимость:** локальный Three.js 0.180.0, зафиксированный lock-файлом. Без сборщика и CDN.

Нет загружаемых моделей, изображений, видео, аудиозаписей, внешних шрифтов или онлайн-сервисов. Кадры в `qa/` — результаты проверки, приложение их не читает.

## Проверка и устройство

```powershell
npm.cmd run check
.\start.cmd --verify
```

Вторая команда запускает тот же трейлер и сохраняет локальные показатели полного показа в `qa/windows-run.json`. Режим проверки не нужен для обычного просмотра.

`src/world.js` — сцена; `src/shaders.js` — шейдеры; `src/timeline.js` — постановка; `src/audio.js` — партитура; `src/main.js` — показ и управление. `server.mjs` — локальный сервер и запуск браузера. Для просмотра конкретного кадра без звука: `http://127.0.0.1:4173/?t=26` (порт печатается в терминале).

Использованы [Three.js](https://threejs.org/docs/), [UnrealBloomPass](https://threejs.org/docs/pages/UnrealBloomPass.html) и [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext).
